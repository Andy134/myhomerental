# Project

## Name

Home Rental

## Goal

Ứng dụng quản lý phòng trọ

Người dùng gồm admin và user

Admin có quyền:
- Đăng nhập
- Tạo mới phòng trọ, chỉnh sửa phòng trọ
- Tạo mới người thuê, chỉnh sửa người thuê
- Tạo mới hợp đồng, chỉnh sửa hợp đồng thuê
- Tạo mới, chỉnh sửa hóa đơn
- Tạo mới, chỉnh sửa danh sách chi phí
- Dashboard thống kê hóa đơn đến hạn thanh toán, quá hạn thanh toán, doanh thu theo năm
